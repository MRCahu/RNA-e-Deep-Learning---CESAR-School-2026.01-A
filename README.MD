## Objetivo

Disponibilizar as entregas de Atividades (AT) e do Trabalho Final (TF) da disciplina, conforme as orientações do professor.

## Organização das entregas

As pastas de entrega ficam diretamente na raiz do repositório.

| Entrega | Nome da pasta | Conteúdo |
| --- | --- | --- |
| Atividade | `Atividade X.Y` | Notebook e demais arquivos solicitados para a atividade. |
| Exemplo de atividade | `Atividade 2.2` | Pasta a criar quando essa atividade for solicitada. |
| Trabalho Final | [Trabalho Final](Trabalho%20Final/) | Pasta reservada para os arquivos do TF. |

A pasta de cada atividade será criada quando houver uma entrega correspondente. A pasta reservada para o TF não representa uma entrega concluída.

**Situação inicial:** nenhum arquivo de atividade ou de trabalho final foi entregue neste repositório.

## Como consultar uma entrega

1. Abra a pasta correspondente à atividade ou ao trabalho final.
2. Leia as instruções locais, se houver.
3. Abra o notebook ou arquivo principal.
4. Consulte a origem dos dados e as dependências descritas na entrega.

## Padrão de qualidade

- Preservar os nomes de pasta exigidos pelo professor.
- Usar nomes descritivos para os arquivos, como `atividade_2_2.ipynb`.
- Organizar notebooks com objetivo, fonte dos dados, metodologia, execução, resultados e conclusão.
- Informar bibliotecas, versões e instruções necessárias para reproduzir a execução.
- Validar o notebook do início ao fim antes da entrega.
- Registrar alterações em commits curtos e descritivos.
- Publicar somente dados e materiais cuja divulgação seja permitida.
